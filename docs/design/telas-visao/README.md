# Telas do VISAO

Mockup completo do app na identidade nova: o corvo no eclipse, o selo VISAO e as cores tinta, papel e âmbar.

| Arquivo | O que é |
|---|---|
| `prototipo-computador.html` | Protótipo clicável do app de desktop (1440×900). Abre direto no navegador, sem servidor. |
| `prototipo-celular.html` | Protótipo clicável do celular (390×844). |
| `mapa-de-funcionalidades.html` | Hermes × VISAO: cada funcionalidade, como ficou e em que tela testar. |
| `telas/*.png` | Print de cada tela e estado, para consulta rápida. |
| `assets/` | Ícones, busto em xilogravura e as fontes (Geist, Geist Mono, Newsreader, Six Caps). |
| `PROMPT_CLAUDE_CODE.md` | O prompt para implementar estas telas no app. |

## Navegar

- No computador, comece em **Entrar** ou em **Primeira vez? Configurar o VISAO**.
- `?tela=chat&tema=escuro` abre direto numa tela e num tema. Telas: `login`, `boasvindas`, `inicio`, `chat`, `projetos`, `caderno`, `rotinas`, `braco`, `agentes`, `canais`, `habilidades`, `ajustes`, `painel`, `ligacao`. Temas: `claro`, `escuro`, `rotulo`.
- `Ctrl+K` abre a paleta de comandos; `Esc` fecha janelas.

## Regras que o mockup segue

- Âmbar `#E39A2E` é só dele: o eclipse, o filete dos pensamentos, o pedido de aprovação, o indicador de atividade, o aviso de versão. Nunca em botões comuns.
- Botão principal é tinta sobre papel; secundário é contorno.
- Fala dele em Newsreader itálico com filete âmbar; dados e horários em Geist Mono; interface em Geist; o nome VISAO em Six Caps.
- O ícone do app é só o corvo no eclipse; o selo com o nome VISAO aparece no login e no material de marca.

Os dados das telas são de exemplo (Lisboa, debounce, testes no Mac).
